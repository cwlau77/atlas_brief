# Home Wire Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Home's "Trending now" chips with an "On the wire" list: real publish times, newsroom-style topics, one click to brief.

**Architecture:** `backend/trending.py` keeps each headline's publish time, asks Haiku to cite headline numbers per topic, and returns `items` (topic plus newest cited time) next to the unchanged `topics`. `lib/trending.ts` reads `items` (falling back to `topics`), and a new `components/TopicWire.tsx` orders, caps, formats and refreshes them. Wire styles replace the `.chips`/`.chip` rules in `routes/home.css`.

**Tech Stack:** FastAPI, pydantic, feedparser, pytest + respx; React 19, TypeScript, Vitest (jsdom), plain CSS with tokens.

**Spec:** `docs/superpowers/specs/2026-10-22-home-wire-design.md`

## Review Focus

1. **Cache-only polling:** with a fresh session copy, the 10-minute check must not call `fetch` (no extra model calls). Pinned in Task 3 (`does not refetch while the session copy is fresh`).
2. **A failed or empty refresh after a good list** must keep the current lines, not drop to "Suggested". Pinned in Task 3.
3. **A same-list refresh** (the hourly backend list unchanged) must highlight nothing. Pinned in Task 3.
4. **Feed entries with no `published_parsed`, or a model citing `0`, negative, `true` or out-of-range numbers,** give `published_at: null` without failing. Pinned in Task 1.

Behaviour (from the spec):
- Live when the last good load had items: header "On the wire" plus `Updated {formatWireTime(generatedAt, timeZone)}`; lines are `orderWire(items).slice(0, WIRE_LINES)`, each showing `formatWireTime(publishedAt, timeZone)` (blank for null, cell still rendered).
- Fallback: header "Suggested", no stamp, `fallback` topics with blank times.
- Each line is one `<button type="button">` inside an `<li>`, `aria-label` = `Brief me on {topic}, {time}` (drop `, {time}` when blank), `disabled` while `disabled`; click calls `onPick(topic)`.
- Load on mount; then every `REFRESH_MS = 10 * 60_000` and on `visibilitychange`, call `loadTrending` only when `document.visibilityState === 'visible'`. An empty result keeps the current lines. A result whose topics equal the current ones changes nothing.
- New marking: on a refresh that replaces a live list, lines in the visible slice whose topic (casefolded) wasn't in the previous list get `is-new` for `NEW_MS = 1600`, then lose it. Never on first load, never for a fallback→live switch, never outside the visible slice.
- Abort and clear the interval, listener and timers on unmount.
