# Atlas UI Spec 3 (Globe Zoom + Carousel, Top Stories, Routes, Arcs, Named Cities, Images) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Capture article images and named cities on the backend. On the frontend, add a globe click-to-zoom with a centred story carousel, a top-stories strip, transit-style routes that replace the loose threads, and matching globe arcs.

**Architecture:**
- **Backend** (`backend/`): optional `image_url` on `Article`/`SourceCitation`, and an optional `place` on `KeyDevelopment`. The place is resolved by `backend/places.py` against a bundled GeoNames CSV, from a `city` string the synthesis model returns.
- **Frontend** (`frontend/`): pure, unit-tested modules (`lib/routes.ts`, `globe/arcs.ts`, normalisation) feed React components (`StoryCard`, `StoryCarousel`, `TopStories`, the route lanes in `Timeline`).
- **Shared highlight state** lives in a `useRouteHighlight` hook owned by `StoryTab`, so the timeline, key, tabs and globe arcs all light together.
- **Globe engine** changes (zoom, arcs) are verified in the browser, since WebGL doesn't run in jsdom.

**Tech Stack:** Python 3.11 / FastAPI / pydantic / pytest + respx. React 19 / react-router 7 / TypeScript 6 / Vite 8 / Vitest 4 / three.js 0.185.

**Spec:** `docs/superpowers/specs/2026-10-19-ui-spec-3-design.md` (§ numbers below refer to it).

## Global Constraints

- **Commands:**
  - Backend, from the repo root: `.venv/bin/python -m pytest backend/tests -q`. If `.venv` is missing: `python3.11 -m venv .venv && .venv/bin/pip install -r backend/requirements-dev.txt`.
  - Frontend, from `frontend/`: prefix with `PATH="$HOME/.local/node/bin:$PATH"`.
- **Every new API field is optional;** older clients and saved briefings must keep working.
- **No new runtime dependencies** in either the frontend or the backend. Read the CSV with the stdlib `csv` module.
- **Images:** keep only `https://` URLs. They're never stored, proxied or generated. Render with `loading="lazy"`, `decoding="async"` and `referrerpolicy="no-referrer"`, plus an `onError` fallback to `RegionMap`.
- **City coordinates always come from the CSV,** never from the model.
- **Spec 2 rules hold:**
  - text uses `--celadon-deep`, and `--celadon` is for graphics only
  - royal blue `--signal` is for alerts, highlights and the logo dot only
  - use the spacing scale `--space-1…9`
  - every motion has a `prefers-reduced-motion` instant equivalent
  - interactive elements are real `button`/`a` elements with names
  - no `window.confirm`
- **Route colours** come in assignment order. Each entry gives the token and the hex the globe uses:
  1. `--ochre` `#9C7026`
  2. `--ink` `#1C231F`
  3. `--celadon` `#5E8A79`
  4. `--sand` `#C7B89C`
  5. `--celadon-deep` `#3A5F52`

  Tensions are solid and contradictions are dashed. There are at most 5 lanes.
- **Zoom and arcs are on `mode="briefing"` globes only.** Home is unchanged.
- **Commit messages** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A publisher image that 404s or is blocked mid-session.** The card swaps to `RegionMap` with no broken-image icon and no layout jump (Task 6 test).
2. **A model city that doesn't match the development's regions or doesn't exist** ("Aden" on an Egypt-only story, "Atlantis"). The place is dropped and the story stays on its region point (Task 4 tests).
3. **A briefing with more than 5 routes, or none.** The busiest 5 get lanes and the others keep their tabs and dots. With none, no key and no lanes are rendered, and the spine sits where it did in spec 2 (Task 8 tests).
4. **A globe point with a single story.** The carousel opens with one centred card, the arrows are disabled, and there are no dots. Pressing Esc or Back with no zoom active is a no-op (Task 7 test).
5. **An old saved briefing (no `image_url`, no `place`) opened after the upgrade.** It renders with region maps and region points, with no crash (Task 5 test).
